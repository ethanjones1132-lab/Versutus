Versutus

A mobile and web client for AI agent gateways.

Why

Hermes ships a desktop app, a TUI, and an HTTP API. It does not ship a mobile client.

Bridging the agent into Telegram or Discord keeps a text box and drops run lifecycle, approval prompts, and tool-call inspection.

What

Versutus is a client. It holds no model credentials. It is not a public relay. The agent stays where you put it.

Gateways

  • Hermes Over HTTP and SSE.
  • Versutus Gate An OpenAI-compatible proxy.
  • OpenClaw Over its WebSocket.

Surfaces

  • Home Connection and live runs.
  • Chat Streaming, with approvals inline.
  • Activity Start a run, approve or deny, stop.
  • Tools Shell only when the gateway advertises one.
  • Voice Hold to talk; a separate opt-in hands-free call with no wake word.
