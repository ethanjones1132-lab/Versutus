Versutus

A mobile and web client for AI agent gateways — your agent stays where you put it.

Point Versutus at a Hermes Agent running on your own machine — over LAN, over Tailscale, or through a gate you control — and drive it from a phone.

Features

Versutus is a client for AI agent gateways, with chat, Bots, agentic runs, approvals and tools — on Android, iOS and the web.

  • Home — connection, capabilities, live runs and approvals.
  • Chat — streaming markdown, slash commands, model picker, offline outbox, tool-call cards and inline run approvals.
  • Activity — start an agentic run, watch live events, approve or deny, stop.
  • Tools — inspect what your gateway offers.
  • Connecting — saved gateways, Tailscale or LAN hosts probed on launch, and versutus://add deep links.
  • Identity — secure on-device profiles and tokens.

Bots

A Bot is a Hermes profile with its own soul, memory, model pin, sessions and crons. The Chat tab opens on a roster of Bots; tapping one opens its own persistent conversation. Each Bot is reached with its own key — if that fails, the request never silently falls back to the default profile.

Voice

Hold-to-talk dictation lands in the composer and never sends by itself; optional spoken replies per Bot; a separate opt-in hands-free call that only starts on an explicit Start call tap. No wake word, no always-listening mode.

Gateways

One portal, many gateways — the app reads what the live gateway advertises and only shows those surfaces.

  • Hermes — HTTP REST + SSE, the primary PC agent.
  • Versutus Gate — a multi-provider gate with an OpenAI-compatible chat proxy, in this repo.
  • OpenClaw — WebSocket adapter for compatible profiles.

Gateways are reachable over LAN or Tailscale, through a gate you control — not through a public relay.

Privacy

Versutus is a client. It holds no model credentials of its own, brokers nothing on anyone else's behalf, and is not a public relay. Approvals stay with you: run approvals, tool-call inspection and per-Bot session scoping all happen on your side of the wire. Your agent stays where you put it.

Status

Versutus is pre-release, single author, actively built. It is not published to any store.
