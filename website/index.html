A mobile & web client for AI agent gateways

Meet Versutus: your agent, in your pocket, on your terms.

Point Versutus at a Hermes Agent on your own machine — over LAN, over Tailscale, or through a gate you control — and drive it from a phone.

Why it exists

A text box is not an agent surface.

Bridge Hermes Agent into Telegram or Discord and you get a text box: no run lifecycle, no approval prompts, no tool-call inspection, no capability discovery, no per-Bot session scoping.

Versutus speaks to the API server directly, so run lifecycle, approvals, tool-call inspection, capability discovery and per-Bot session scoping all survive the trip to your phone. Your agent stays where you put it.

Features

Everything the agent does, in your pocket.

Versutus is a client — Android, iOS and web — for AI agent gateways. It never assumes a capability: it reads what the live gateway advertises and shows only the surfaces that exist.

  • HomeConnection, capabilities, live runs and approvals.
  • ChatStreaming markdown, slash commands, model picker, offline outbox, tool-call cards and inline run approvals.
  • ActivityStart an agentic run, watch live events, approve or deny, stop.
  • ToolsShell when advertised; otherwise RPC and Agent commands.
  • ConnectingSaved gateways, Tailscale or LAN hosts probed on launch, and versutus://add deep links.
  • IdentitySecure on-device profiles and tokens.

For example, the Shell tab appears only when a gateway advertises a terminal. Otherwise Tools offers RPC and Agent commands — the app shows what the gateway actually supports, never a promise of what it does not.

Bots

A roster, not a chat.

A Bot is a Hermes profile with its own soul, memory, model pin, sessions and crons. The Chat tab opens on a roster of Bots; tapping one opens its own persistent conversation. Each Bot is reached with its own key — if that fails, the request never silently falls back to the default profile. It fails closed, not open.

Gateways

One portal, many gateways.

Versutus talks to the API server directly, over LAN, over Tailscale, or through a gate you control — never through a public relay.

  • Hermes

    HTTP REST + SSE — the primary PC agent. This is the open Hermes Agent, with its own API server.

  • Versutus Gate

    A multi-provider gateway with an OpenAI-compatible chat proxy, open source alongside the app.

  • OpenClaw

    WebSocket adapter for compatible profiles.

Hermes Agent is a desktop app, a TUI and an HTTP API server — but no mobile client, and the open issue asking for one has been open for a while. Versutus is that missing client.

Voice

Your keys, not your ears.

Hold-to-talk dictation drops text into the composer and never sends by itself. Spoken replies can be enabled per Bot. And the hands-free call is a separate, opt-in mode that only starts on an explicit Start call tap — never ambiently.

  • No wake word. Versutus never listens for a word in the background.
  • No always-listening mode. Dictation is a held tap; the call is a started tap. Nothing else wakes.

Privacy

Your agent stays where you put it.

Versutus is a client. It holds no model credentials of its own, brokers nothing on anyone else's behalf, and is not a public relay.

Run approvals, tool-call inspection and per-Bot session scoping all happen on your side of the wire. The key that reaches a Bot — its own key — either works, or fails closed. There is no silent fallback to a default profile.

  • Holds no credentials. Versutus never carries model keys; your gateway holds them.
  • Brokers nothing. It does not relay, proxy or sell your agent's traffic.
  • Fails closed. A Bot whose key fails is not reached silently through another profile.

Status

Pre-release, actively built.

Versutus is pre-release, single author and actively built. It is not published in any store, and it is honest about that. The source is the whole store door — a link to the repo, and a README that tells you where things stand.
