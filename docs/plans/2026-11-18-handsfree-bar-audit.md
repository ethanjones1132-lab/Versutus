## H1 — Host replay (Windows PowerShell, repo root)

Use the installed Gate voice runtime on the RTX 4060 host; do not replace live models with stubs. `$Evidence` is a private output directory. `--seed` needs an empty directory and uses the existing Gate venv and Kokoro models. Use `--noise-seconds 30` for a smoke run, not for the F5 bar.

```powershell
node gate/cli.mjs voice doctor
npm run --silent voice:replay -- --seed "$Evidence/seed" --noise-seconds 600
npm run --silent voice:replay -- --manifest "$Evidence/seed/corpus.json" --out "$Evidence/voice-replay-seed.json"
npm run --silent voice:replay -- --manifest "$Evidence/corpus/corpus.json" --out "$Evidence/voice-replay-baseline.json"
# After W6, rerun the exact same corpus:
npm run --silent voice:replay -- --manifest "$Evidence/corpus/corpus.json" --baseline "$Evidence/voice-replay-baseline.json" --out "$Evidence/voice-replay-after.json"
```

The seed includes 30 clean samples, 24 controlled 0.5–3 s mid-thought pauses, 20 simulated echo exposures, and four synthetic noise proxies. Build the acceptance corpus before tuning: add Ethan's read and spontaneous speech, more trials around 1.5–2.5 s so 5% is measurable, and ten minutes each of real TV, kitchen, cough and click recordings. Keep the original baseline on the same labels/models. Each WAV is mono little-endian 16-bit PCM at 16 kHz, beside the versioned JSON manifest. `speechEndMs` is measured from the beginning of its WAV; optional `pauseMs` labels a mid-thought pause, not trailing silence. `kind: "echo"` is a speech clip that starts a reply before the harness feeds a delayed, attenuated copy of returned PCM into capture; it cannot substitute for the phone's loudspeaker/AEC test.

```json
{
  "version": 1,
  "clips": [
    { "id": "ethan-01", "kind": "speech", "wav": "ethan-01.wav", "source": "ethan", "reference": "What did we decide?", "speechEndMs": 1780 },
    { "id": "kitchen-01", "kind": "noise", "wav": "kitchen-01.wav", "noiseKind": "kitchen", "source": "recorded" }
  ]
}
```

The command writes version-1 JSON to stdout (and optionally `--out`), with `backend`, `rows`, `failures`, and `metrics.F1/F4/F5/F6/F7`. The short table goes to stderr. `null` means missing/inapplicable, not zero; the report has exposure counts and fails the process when clips fail to run. No transcript or audio is included in a successful report. `scripts/voice-replay-host.mjs:168–311` attaches the real socket and worker to a loopback-only simulated phone and scripted zero-TTFT backend; `gate/__tests__/voice-replay-host.test.mjs` checks sidecars, split/merge, timing and score denominators, not real model performance.
