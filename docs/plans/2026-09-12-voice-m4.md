## Task 4.2 — The pure chooser names the engine and any fallback

**Files:** create `src/lib/voice/voice-engine-choice.ts`; test `__tests__/voice-engine-choice-test.ts`.

- [ ] **Step 1: Write the failing tests** as a table over every combination of
  preference (`auto`/`local`/`codex`/`phone`) × engine readiness × kill switch:
  - `phone` always chooses `phone` and never falls back.
  - the kill switch (`enabled: false`) chooses `phone` and names why.
  - `auto` chooses `local` when ready, else `codex` when ready, else `phone`.
  - an explicit ready engine is chosen.
  - an explicit unavailable engine chooses the next ready engine in `local` → `phone`
    order with `fellBackFrom` and the requested engine's reason.
- [ ] **Step 2: Run to confirm they fail.** `npx jest __tests__/voice-engine-choice-test.ts`
- [ ] **Step 3: Implement** `chooseVoiceEngine(preference, capabilities)` returning
  `{ engine, fellBackFrom?, reason? }`. No UI, no storage, no React.
- [ ] **Step 4: Run** — PASS.
- [ ] **Step 5: Commit.** `feat(voice): one pure chooser names the engine and any fallback`
