# Milestone M1 — Feasibility spikes on this PC

Expansion of the M1 rows of `docs/plans/2026-09-12-realtime-voice-plan.md` §M1 into
the Phase 0 TDD step format (failing test → run → implement → run → commit). The plan
fixes the contracts, files and acceptance; this document fixes the steps, code and
commands.

M1 writes no product code. It answers the questions M2–M5 depend on and leaves
artifacts the later milestones reuse:

- `scripts/voice-spikes/s1-codex-realtime.mjs` → `docs/plans/voice-spikes/s1-*.jsonl`
- `scripts/voice-spikes/s2-local-pipeline.py` → captures, `gate/voice-worker/models.lock.json`
- `docs/plans/voice-spikes/DECISIONS.md`

Rules carried from Phase 0:

- `npm run verify` must exit 0 before every commit. Spike *scripts* are pinned by a
  `node:test` in `scripts/__tests__/`, which `npm run test:gate` already runs.
- The only extra process this sprint may start is `codex app-server` (M1 S1). Never
  start the Versutus Gate, Hermes, OpenClaw, or call the live gateway.
- Fixtures that need Ethan's phone are PENDING-DEVICE; the synthetic-only steps run
  without them. Do not invent recordings.
- Run the spike scripts in the foreground (they are short); give each a hard timeout.

## Task 1.1 — The S1 harness names the experiment before it runs

**Files:**
- Create: `scripts/voice-spikes/s1-codex-realtime.mjs`
- Test: `scripts/__tests__/voice-spike-s1.test.mjs`

- [ ] **Step 1: Write the failing test.** Create `scripts/__tests__/voice-spike-s1.test.mjs`:

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

const here = dirname(fileURLToPath(import.meta.url));
const source = readFileSync(join(here, '..', 'voice-spikes', 's1-codex-realtime.mjs'), 'utf8');

test('S1 spawns codex app-server with and without the realtime feature flag', () => {
  assert.match(source, /'app-server'/);
  assert.match(source, /features\.realtime_conversation=true/);
  assert.match(source, /withFlag|withoutFlag/);
});

test('S1 initialises with the experimental API and probes voices', () => {
  assert.match(source, /experimentalApi:\s*true/);
  assert.match(source, /thread\/realtime\/listVoices/);
});

test('S1 starts a read-only ephemeral thread and a client-managed websocket realtime session', () => {
  assert.match(source, /sandbox:\s*'read-only'/);
  assert.match(source, /approvalPolicy:\s*'never'/);
  assert.match(source, /ephemeral:\s*true/);
  assert.match(source, /outputModality:\s*'audio'/);
  assert.match(source, /type:\s*'websocket'/);
  assert.match(source, /clientManagedHandoffs:\s*true/);
});

test('S1 streams both input rates, appends speech and stops, and writes a JSONL capture', () => {
  assert.match(source, /appendAudio/);
  assert.match(source, /24000/);
  assert.match(source, /16000/);
  assert.match(source, /appendSpeech/);
  assert.match(source, /thread\/realtime\/stop/);
  assert.match(source, /s1-\$\{|s1-/);
});
```

- [ ] **Step 2: Run to confirm it fails.**
  Run: `npm run test:gate`
  Expected: FAIL with `ENOENT` for `s1-codex-realtime.mjs`.

- [ ] **Step 3: Implement the harness.** Create `scripts/voice-spikes/s1-codex-realtime.mjs`.
  It reuses `createStdioJsonRpc` and writes one JSONL line per notification with a
  monotonic timestamp. It spawns the child twice — `['app-server']` and
  `['-c', 'features.realtime_conversation=true', 'app-server']` — and for each:
  `initialize { clientInfo, capabilities: { experimentalApi: true } }`; `thread/realtime/listVoices`
  (record result or error); `thread/start { ephemeral: true, sandbox: 'read-only', approvalPolicy: 'never', cwd: <empty dir> }`;
  `thread/realtime/start { threadId, outputModality: 'audio', transport: { type: 'websocket' }, clientManagedHandoffs: true, includeStartupContext: false }`;
  stream a synthetic 1 s 440 Hz tone WAV at 24000 and again at 16000 through `appendAudio`;
  `appendSpeech { threadId, text: 'Versutus voice check.' }`; wait 2 s; `thread/realtime/stop`.
  Every step logs `{ ts, run, step, direction, payload }`; errors are captured, never thrown
  past the top level, so Q6 (unavailable/over-allowance) is a recorded line. `--out`
  defaults to `docs/plans/voice-spikes/s1-<ISO timestamp>.jsonl`. It creates the empty
  voice workspace at `%LOCALAPPDATA%\Versutus\Gate\voice\codex-workspace` if absent.

- [ ] **Step 4: Run to confirm it passes.**
  Run: `npm run test:gate`
  Expected: PASS, existing gate tests unchanged.

- [ ] **Step 5: Commit.**

```bash
git add scripts/voice-spikes/s1-codex-realtime.mjs scripts/__tests__/voice-spike-s1.test.mjs
git commit -m "spike(voice): a codex app-server harness that asks the realtime questions M3 depends on"
```
