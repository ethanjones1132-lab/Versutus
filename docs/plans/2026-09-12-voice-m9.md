## Task 9.1 — The audit line, with no transcript text

§4.9/M9: `%LOCALAPPDATA%\Versutus\Gate\voice\audit.jsonl` lines
`{ ts, deviceId, botId, engine, fellBackFrom, turns, secondsListening, secondsSpeaking, p50FirstAudioMs, error }`.

- [ ] **Step 1: Write the failing test.** `gate/__tests__/voice-audit.test.mjs`:
  `buildAuditLine(summary)` returns exactly the ten fields; a summary carrying `text`,
  `partial`, `reply` and `transcript` does not leak them (redaction); missing fields become
  null/0; `createVoiceAudit({ dir, now, append })` appends one JSON line per call to
  `audit.jsonl` and creates the directory.
- [ ] **Step 2: Run to confirm it fails.**
  `cd gate; node --test "__tests__/voice-audit.test.mjs"`.
- [ ] **Step 3: Implement `audit.mjs`** with the fixed field list and a `redact` that keeps
  only scalar allow-listed fields (so an object field can never smuggle text), then
  `createVoiceAudit` writing JSONL. Wire it in `media-socket.mjs`: the `audit` effect calls
  an injected `audit(entry)`; the call records `deviceId`, `botId`, `engine`, the end
  reason as `error`, and a turn count. `server.mjs` constructs the sink at
  `join(voicePaths().root, 'audit.jsonl')`.
- [ ] **Step 4: Run** — PASS.
- [ ] **Step 5: The gate and commit.** `npm run verify` EXIT=0, then:

```bash
git add gate/core/voice/audit.mjs gate/__tests__/voice-audit.test.mjs gate/core/voice/media-socket.mjs gate/core/server.mjs
git commit -m "feat(voice): every call leaves an audit line that carries no words"
```

## Task 9.2 — The kill switch

§4.9: the Gate `voice` config block gates each engine; the kill switch leaves only `phone`.

- [ ] **Step 1: Write the failing test.** `gate/__tests__/voice-runtime.test.mjs`:
  `readVoiceConfig({ paths })` defaults to everything enabled; a `voice.json` with
  `enabled: false` makes `voiceStatus` report `enabled: false` and both engines `disabled`
  with a named reason; `engines.local.enabled: false` disables only `local` while `codex`
  keeps its runtime state.
- [ ] **Step 2: Run to confirm it fails.**
  `cd gate; node --test "__tests__/voice-runtime.test.mjs"`.
- [ ] **Step 3: Implement** `readVoiceConfig` (reads `<root>/voice.json`, tolerant of a
  missing or malformed file) and apply it in `voiceStatus`: a disabled Gate reports
  `enabled: false`; a disabled engine reports `state: 'disabled'` with a reason, so
  `chooseEngine` never grants it and the app falls to `phone`.
- [ ] **Step 4: Run** — PASS.
- [ ] **Step 5: The gate and commit.** `npm run verify` EXIT=0, then:

```bash
git add gate/core/voice/runtime.mjs gate/__tests__/voice-runtime.test.mjs
git commit -m "feat(voice): a Gate config can switch voice off or off per engine"
```
