# Milestone M8 — Entry points

Expansion of the M8 rows of `docs/plans/2026-09-12-realtime-voice-plan.md` §M8 into the
Phase 0 TDD step format (failing test → run → implement → run → commit). §4.4 is the
entry-point contract: an unsigned `versutus://call` link must never open the microphone.

Inputs:
- `src/lib/gateway/deep-link.ts` already folds `add` / `chat` / `compose`; the call link is
  the fourth target and the vocabulary the widget plan consumes.
- `modules/handsfree-voice/` is the native module; `modules/versutus-widget/**` belongs to
  the parallel widget run and is never touched here.

Rules carried from Phase 0:
- `npm run verify` must exit 0 before every TypeScript commit.
- Kotlin changes run `.\gradlew.bat :handsfree-voice:testDebugUnitTest` (long helper) and
  the JVM suite must report `BUILD SUCCESSFUL`.
- No `adb`; device acceptance is PENDING-DEVICE.
- Never weaken a test to pass it.

## Task 8.1 — The call link is parsed

§4.4: `versutus://call[?bot=…][&engine=…][&autoStart=1&ts=…&sig=…]`.

- [ ] **Step 1: Write the failing test.** `__tests__/deep-link-target-test.ts`: `call` with
  no query is `{ kind: 'call', engine: 'auto', autoStart: false }`; an unknown `engine` is
  `auto`; `engine=local`/`codex`/`phone` are carried; `autoStart=1` alone (no ts/sig) is
  `autoStart: false`; `autoStart=1&ts=<ms>&sig=<b64>` is `autoStart: true` with
  `signature: { ts, sig }`; the Bot id is trimmed and optional; a repeated param takes its
  first value; `CALL`/`call/` are not targets.
- [ ] **Step 2: Run to confirm it fails.**
  `npx jest __tests__/deep-link-target-test.ts`.
- [ ] **Step 3: Implement** in `deepLinkTarget`. `engine` is one of
  `auto | local | codex | phone`, defaulting to `auto`. `autoStart` is `true` only when
  `autoStart === '1'` **and** `ts` parses to a finite number **and** `sig` is a non-empty
  string. `signature` is present exactly then.
- [ ] **Step 4: Run** — PASS.
- [ ] **Step 5: The gate and commit.** `npm run verify` EXIT=0, then:

```bash
git add src/lib/gateway/deep-link.ts __tests__/deep-link-target-test.ts
git commit -m "feat(voice): a call link carries its Bot, engine and signed auto-start"
```

## Task 8.2 — The launch key signs and verifies (JVM)

§4.4: HMAC-SHA256 over `call|<botId>|<engine>|<ts>`, base64url, valid 30 days.

- [ ] **Step 1: Write the failing test.** `HandsfreeLaunchKeyTest.kt`: a key signs a payload
  and the same key verifies it; a different key or a tampered payload fails; a timestamp
  older than 30 days fails; a malformed signature fails rather than throwing; the payload is
  exactly `call|scout|local|1700000000000` and an empty Bot id is `call||auto|<ts>`.
- [ ] **Step 2: Run to confirm it fails.**
  Long helper: `node docs/plans/.run-long.mjs start gradle-m8t2 android '.\gradlew.bat :handsfree-voice:testDebugUnitTest'`.
- [ ] **Step 3: Implement `HandsfreeLaunchKey.kt`** as pure JVM helpers — `payload`,
  `sign(key: SecretKey, payload)`, `verify(key: SecretKey, payload, signature, ts, now)` —
  plus `parse(url)` and `verifyFromKey(key, url, now)`. Signature compare is constant-time.
  `MAX_AGE_MS = 30 days`. No Android import in the pure path.
- [ ] **Step 4: Run** — `BUILD SUCCESSFUL`, the new test green.
- [ ] **Step 5: The gate and commit.** `npm run verify` EXIT=0, then:

```bash
git add modules/handsfree-voice/android/src
git commit -m "feat(voice): a signed call link proves the widget made it"
```

## Task 8.3 — The app can verify a launch link

  `verifyFromKey(key, "versutus://call?bot=scout&engine=local&autoStart=1&ts=…&sig=…", now)`
  is true; an unsigned link, a tampered link, and an expired link are false.
- [ ] **Step 2: Run to confirm it fails.**
