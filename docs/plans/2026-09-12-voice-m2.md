# Milestone M2 — Gate voice sessions and the phone's media socket (engine-agnostic)

Expansion of the M2 rows of `docs/plans/2026-09-12-realtime-voice-plan.md` §M2 into the
Phase 0 TDD step format. The plan fixes the contracts, files and acceptance; this
document fixes the steps, code and commands.

M1 changed one input: the `codex` engine does not ship (`docs/plans/voice-spikes/DECISIONS.md`).
M2 is engine-agnostic and unchanged; where M2 refers to `codex`, read "the second engine
slot", which today is disabled. `auto` resolves `local` → `phone`.

- No paid API is called; no live Gate, Hermes or OpenClaw is started.
- Device acceptance is PENDING-DEVICE; land code, tests and the build.
