# Release Notes

The release notes live in [`CHANGELOG.md`](../../CHANGELOG.md) at the repository root. It
carries the `Unreleased` section and the notes for the version in `package.json`, grouped
as Added / Changed / Fixed.

This file used to be the notes themselves. It is now a pointer so there is one source: the
GitHub release body is a copy of the tagged `CHANGELOG.md` section. The procedure for
writing a release's notes is "Release notes" in
[`RELEASE-PLAN.md`](RELEASE-PLAN.md#release-notes).
