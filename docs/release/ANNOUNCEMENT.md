# Versutus — announcement (Hermes community)

Versutus is a client for AI agent gateways, Hermes included: chat, Bots, agentic runs, approvals and tools against an agent you run yourself. It holds no model credentials and is not a public relay.

To try it without installing anything, build the browser demo and serve it locally:

```bash
npm run export:web
npm run serve:web        # serves dist/ on port 8090
```

Open the URL the server prints against a gateway that allows that origin. The demo is the browser build of the same client, not the phone app: no Play Store install, no OS-keychain app lock, and no device push notifications. Play Store open testing and the public GitHub release are in progress; links will be shared once they exist.
